## 日本語 — アシスタント併用への変更

Rokid Glasses向けオーディオスペクトルアナライザの**プレリリース**です。

- Android 11以降でsetPrivacySensitive(false)へ変更し、排他的なCAM／COMM入力を避ける構成へ移行。
- フォーカス喪失やActivity一時停止でマイクを解放し、戻ると再開。ユーザーが選んだHOLDは維持。
- 音声前処理を変更せず、アシスタント・ヘッドセット・メディアキーをシステムへ渡す。
- OSが入力を無音化した場合はWAITINGを表示し、同じ入力で復帰を待つ。

**既知の制限:** 実機の写真・動画ではMIC / 48000 Hz / NONPRIVATEのままWAITINGが継続し、解析が始まりませんでした。この版には待機時間の上限がなく、入力が戻らない場合に進めない問題があります。実音解析とアシスタント併用の成功は確認できていません。

検証: 数値・状態29件、マイク制御22件、Activity 12件、描画16状態。Android APIの代替実装／Java2Dでの検証であり、実機での実音解析の成功を保証しません。

Assetsの`RokidSpectrum-1.0.2.apk`をインストールし、マイクを許可してください。API 26以上。以前の版と同じ署名・パッケージ名です。DEMOは合成信号、dBFSはdB SPL／dBAではありません。

## English — Non-private capture for assistant coexistence

An experimental **prerelease** of the microphone audio spectrum HUD for Rokid Glasses.

- Switches to setPrivacySensitive(false) on Android 11+ and avoids private CAM/COMM capture.
- Releases the microphone on focus loss or Activity pause, resumes on return and preserves user-selected HOLD.
- Leaves audio preprocessing unchanged and passes assistant, headset and media keys through.
- Shows WAITING while Android silences the stream and waits on the same input for recovery.

**Known limitations:** Device photos and video show persistent WAITING on MIC / 48000 Hz / NONPRIVATE without starting analysis. This version can wait indefinitely when input never recovers. Successful live analysis and assistant coexistence have not been confirmed.

Verification: 29 numerical/state tests, 22 audio lifecycle tests, 12 Activity tests and 16 render states. These use Android framework doubles and Java2D; they do not establish successful live capture on hardware.

Install `RokidSpectrum-1.0.2.apk` from Assets and allow microphone access. Requires API 26+. The APK retains the same original signing certificate and package name as earlier versions. DEMO is synthetic; dBFS is not dB SPL/dBA.

## インストール / Installation

```sh
adb install -r -g RokidSpectrum-1.0.2.apk
adb shell am start -n dev.xenoah.rokidspectrum/dev.xenoah.spectrum.MainActivity
```

[この版のREADME / Version README](https://github.com/Xenoah/rokid-spectrum-hud/blob/v1.0.2/README.md)

APKは元の署名済みファイルです。ソースZIPはこの公開コミットから生成し、元のアプリコードに日英ドキュメントと写真を加えています。SHA256SUMS.txtで添付ファイルを確認できます。秘密鍵は含みません。
The APK is the original signed build. The source ZIP is generated from this published commit, with unchanged application code plus bilingual documentation and photos. SHA256SUMS.txt covers the attached files. No private signing key is included.
