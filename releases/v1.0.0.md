## English — Initial spectrum HUD

An experimental **prerelease** of the microphone audio spectrum HUD for Rokid Glasses.

- Adds a 48-band spectrum, waterfall and 12 ms waveform view.
- Uses an 8,192-point Hann-windowed FFT with dominant frequency, AC RMS/peak dBFS, clipping and peak hold.
- Provides a green 480 × 400 HUD, tap/swipe/key controls, HOLD and a microphone-free DEMO mode.
- AUTO tries supported RAW, VOICE, MIC and DEFAULT inputs with 48 / 44.1 / 32 / 16 kHz fallback.

**Known limitations:** Device feedback confirms that the UI opens but reports MIC BUSY. Successful live microphone analysis has not been confirmed. The device screenshot documents this issue. Assistant coexistence is not guaranteed.

Verification: 27 numerical/state tests, 10 audio lifecycle tests, 0 Activity tests and 12 render states. These use Android framework doubles and Java2D; they do not establish successful live capture on hardware.

Install `RokidSpectrum-1.0.0.apk` from Assets and allow microphone access. Requires API 26+. The APK retains the same original signing certificate and package name as earlier versions. DEMO is synthetic; dBFS is not dB SPL/dBA.

## インストール / Installation

```sh
adb install -r -g RokidSpectrum-1.0.0.apk
adb shell am start -n dev.xenoah.rokidspectrum/dev.xenoah.spectrum.MainActivity
```
