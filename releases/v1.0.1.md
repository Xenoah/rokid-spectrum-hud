## 日本語 — MIC BUSY対策

Rokid Glasses向けオーディオスペクトルアナライザの**プレリリース**です。

- AUTOの最初の入力をMICにし、VOICE、対応時のRAW、CAM、DEFAULTも検査。
- 録音開始後の無音化にも入力切り替えを適用し、ミュート・入力方式・レートを診断表示。
- Android 11以降でsetPrivacySensitive(true)を要求し、INPUT: CAMを追加。

**既知の制限:** この版の排他的なマイク設定は、アシスタントとの同時利用を妨げる可能性があります。修正過程を残すための過去版です。実機でMIC BUSYが解消した確認はありません。併用向けの設定変更は1.0.2以降です。

検証: 数値・状態28件、マイク制御21件、Activity 0件、描画14状態。Android APIの代替実装／Java2Dでの検証であり、実機での実音解析の成功を保証しません。

Assetsの`RokidSpectrum-1.0.1.apk`をインストールし、マイクを許可してください。API 26以上。以前の版と同じ署名・パッケージ名です。DEMOは合成信号、dBFSはdB SPL／dBAではありません。

## English — MIC BUSY recovery attempt

An experimental **prerelease** of the microphone audio spectrum HUD for Rokid Glasses.

- Tries MIC first in AUTO, followed by VOICE, supported RAW, CAM and DEFAULT.
- Extends recovery to streams silenced after capture starts and adds mute/source/rate diagnostics.
- Requests setPrivacySensitive(true) on Android 11+ and adds the CAM input option.

**Known limitations:** This version requests private capture, which can interfere with simultaneous assistant use. It is published as a historical development step; recovery on the physical device was not confirmed. Non-private capture is introduced in 1.0.2.

Verification: 28 numerical/state tests, 21 audio lifecycle tests, 0 Activity tests and 14 render states. These use Android framework doubles and Java2D; they do not establish successful live capture on hardware.

Install `RokidSpectrum-1.0.1.apk` from Assets and allow microphone access. Requires API 26+. The APK retains the same original signing certificate and package name as earlier versions. DEMO is synthetic; dBFS is not dB SPL/dBA.

## インストール / Installation

```sh
adb install -r -g RokidSpectrum-1.0.1.apk
adb shell am start -n dev.xenoah.rokidspectrum/dev.xenoah.spectrum.MainActivity
```
